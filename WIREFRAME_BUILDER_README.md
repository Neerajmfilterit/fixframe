# 🎨 Wireframe Builder - Dashboard Creator

A powerful drag & drop wireframe builder for creating custom dashboard prototypes. Perfect for designers and developers to create blueprints that can be quickly implemented.

## ✨ Features

### 🔧 **Component Library**
- **📊 Charts**: Bar, Line, Pie/Donut, Area, Scatter plots
- **📋 Tables**: Data tables with customizable columns
- **🔘 Inputs**: Buttons, Text fields, Dropdowns
- **🎨 Layout**: Cards, Images, Navigation components

### 🎯 **Drag & Drop Interface**
- Intuitive drag and drop from component library
- Real-time positioning and resizing
- Grid-based layout system
- Visual feedback during interactions

### ⚙️ **Customization Panel**
- **Style Tab**: Colors, typography, dimensions
- **Layout Tab**: Size, positioning, chart types
- **Data Tab**: Upload CSV/JSON, generate sample data

### 📤 **Export Options**
- **JSON Export**: Developer-ready layout configuration
- **PDF Export**: Client presentations and documentation
- **Import/Export**: Save and share wireframes

### 🔄 **Live Preview**
- Toggle between Edit and Preview modes
- Real-time component updates
- Clean presentation view

## 🚀 Quick Start

1. **Select Components**: Choose from the categorized component library
2. **Drag & Drop**: Place components on the canvas
3. **Customize**: Click components to modify properties
4. **Export**: Save as JSON for development or PDF for clients
